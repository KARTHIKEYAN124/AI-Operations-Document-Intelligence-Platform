# Wireframes

## Landing

- Header: product name, docs, analysis, search, login/register.
- First viewport: direct product statement and upload/search preview.
- Sections: workflow, AI-likelihood caveat, RAG references, admin controls.

## Dashboard

- Left navigation: Dashboard, Upload, Analysis, Search, Q&A, History, Admin.
- Top bar: system status, model status, queue count, user menu.
- Main grid: upload queue, AI-likelihood report, primary signals, semantic search, analytics cards, processing history.

## Upload

- Drag-and-drop target with MIME, size, duplicate, and corruption validation states.
- Queue list with pending, processing, failed, and completed statuses.

## Analysis

- Summary probability, uncertainty range, confidence label, document type, extracted fields.
- Signal bars for sentence variation, lexical diversity, repetition, predictability, and paragraph structure.
- Plain-language caveat that results are probabilistic.

## Search And Q&A

- Search input for semantic queries.
- Result list with document name, section/page, excerpt, and retrieval score.
- Q&A panel showing answer, cited chunks, and confidence.

## Admin

- User table with roles and status.
- Document oversight table.
- Audit log stream.
